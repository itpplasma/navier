# Full-lattice causal prehistory on the caged source reference system

Date: 2026-09-11. Repository input:
`itpplasma/navier@b234bfac9fc7de2c6a0fa8bd70bc10f4fd0ea024`.

**Status: author theorem for the complete infinite frozen source-reference Fourier lattice.** The all-orders spectral cage has a finite unstable spectrum consisting of exactly four growing source branches (plus their reality partners) and a uniformly stable complement. Keeping the **full Navier--Stokes quadratic convolution on the entire lattice**, a Lyapunov--Perron argument constructs a local backward-eternal unstable manifold. Every damped Fourier mode is generated causally from the four growing coordinates; no pulse restart, finite Galerkin closure, or independently initialized stable mode is used.

The quadratic stable-manifold coefficient at the designated daughter must be retuned relative to the instantaneous calculation because the two parent decompositions have different time-growth denominators. After this exact retuning, the daughter has zero positive-branch coefficient and a strictly nonzero negative-branch coefficient. Thus the desired decaying source branch is generated by **one continuous nonlinear reference prehistory**.

This theorem is for the frozen source principal/reference system on its rank-two periodic lattice. It is not yet the physical finite-`L`, moving-label, whole-space source history and is not an unforced `R3` Navier--Stokes solution.

## 1. The complete frozen reference equation

Let `Lambda` be the rank-two frequency lattice

    k_(m,z)=((3m-z)/10,0,z),      m,z in Z,               (1.1)

from `2026-09-11-source-all-orders-spectral-cage.md`, and let `T_Lambda` denote the dual two-dimensional torus. Work with real, zero-mean, divergence-free three-component fields on this torus whose Fourier support lies in `Lambda`.

Fix

    mu=3/5,
    c_0=-1,
    lambda_0=1.                                           (1.2)

For a nonzero frequency `k=(x,0,z)` with `z!=0`, put

    s=x/z,
    n=(s,0,1).                                             (1.3)

Take the frozen source connection matrix, for any fixed real `omega`,

    K_0=[[0,1,-omega],
         [1,0,0],
         [omega,0,0]],                                    (1.4)

and define on the transverse plane

    A(k)=-K_0+n (n^T K_0)/|n|^2.                          (1.5)

For `z=0`, use the continuous radial-normal limit `n=e_1`; on `k^perp` the multiplier (1.5) is zero. The multiplier is uniformly bounded because the second term is an orthogonal rank-one projection composed with `K_0`.

For `z!=0`, the exact transverse eigenvectors are

    a_+(s)=(1,-sqrt(1+s^2),-s),
    a_-(s)=(1,+sqrt(1+s^2),-s),                           (1.6)

with eigenvalues

    +/- 1/sqrt(1+s^2).                                    (1.7)

They are orthogonal:

    a_+(s).a_-(s)=0.                                      (1.8)

Consider the complete semilinear equation

    partial_t u = L u + N(u),                             (1.9)

    L=A(D)+mu Delta,
    N(u)=-P_Leray[(u.grad)u].                             (1.10)

No Fourier truncation is imposed. Since the lattice is closed under addition, (1.9) preserves it exactly.

This is the frozen source-reference perturbation equation, not the original physical whole-space target. Its nonlinear term is nevertheless the full incompressible Navier--Stokes quadratic convolution on the lattice.

## 2. Exact hyperbolic splitting

For `z!=0`, the two linear rates are

    gamma_+ = +1/sqrt(1+s^2)-mu z^2(1+s^2),
    gamma_- = -1/sqrt(1+s^2)-mu z^2(1+s^2).               (2.1)

The spectral-cage theorem proves that the positive branch grows only at the four `z=1` sites

    s=-2/5,-1/10,1/5,1/2,                                (2.2)

and at their conjugate reality partners. Every other nonzero mode/branch is stable.

The exact endpoint inequalities even give coarse uniform margins convenient for the nonlinear proof:

    gamma_u >= 1/10                                       (2.3)

on every unstable eigenmode, because the weakest parent obeys

    2/sqrt(5)-3/4 >1/10,                                  (2.4)

while

    gamma_s <= -1/100                                     (2.5)

on the stable complement. For the nearest nonparent `z=1` site,

    10/sqrt(149)-447/500 <-1/100.                         (2.6)

The nearest nonzero radial mode has rate

    -(3/5)(3/10)^2=-27/500<-1/100,                        (2.7)

and `|z|>=2` is much more strongly damped. Negative eigenbranches are also more strongly stable.

Let `P_u,P_s` be the corresponding orthogonal Fourier spectral projections. The unstable space is finite dimensional.

## 3. Lyapunov--Perron construction with every stable mode retained

Fix an integer `r>2`. On `H^r(T_Lambda)`, `A(D)` is bounded and `mu Delta` is sectorial, so `L` generates an analytic semigroup. On the stable subspace one has the standard parabolic estimate

    ||e^{t L_s}||_(H^(r-1)->H^r)
       <= C (1+t^(-1/2)) e^{-delta_s t},      t>0,         (3.1)

for some `delta_s>0` that may be taken below `1/100`. On the finite-dimensional unstable space,

    ||e^{t L_u}|| <= C e^{delta_u t},        t<=0,        (3.2)

with `delta_u=1/10` admissible.

The full NS nonlinearity satisfies

    ||N(u)-N(v)||_(H^(r-1))
       <= C_r (||u||_Hr+||v||_Hr)||u-v||_Hr.               (3.3)

Choose, for example,

    alpha=1/50,                                            (3.4)

so `2 alpha<delta_u`. For trajectories on `(-infinity,0]`, set

    ||u||_X=sup_(t<=0) e^{-alpha t} ||u(t)||_Hr.           (3.5)

For a prescribed small unstable coordinate `xi=P_u u(0)`, define

    Phi_xi(u)(t)
      = e^{tL_u} xi
        - integral_t^0 e^{(t-s)L_u} P_u N(u(s)) ds
        + integral_-infinity^t e^{(t-s)L_s} P_s N(u(s)) ds. (3.6)

The stable integral is finite because of the `t^{-1/2}` smoothing in (3.1) and the quadratic `e^{2 alpha s}` decay. The unstable integral is bounded in the norm (3.5) because `2 alpha<delta_u`. Equations (3.1)--(3.3) give

    ||Phi_xi(u)||_X <= C||xi||+C||u||_X^2,

    ||Phi_xi(u)-Phi_xi(v)||_X
       <= C (||u||_X+||v||_X)||u-v||_X.                   (3.7)

Therefore, for `||xi||` sufficiently small, (3.6) is a contraction on a ball of radius `O(||xi||)`. Its unique fixed point is a full mild solution of (1.9) for every `t<=0`, satisfies

    ||u(t)||_Hr <= C e^{alpha t}||xi||,                   (3.8)

and tends to zero as `t->-infinity`.

At `t=0`, the stable component

    h(xi)=P_s u(0)
         =integral_-infinity^0 e^{-sL_s}P_s N(u(s)) ds     (3.9)

is `O(||xi||^2)`. The fixed-point map is analytic in `(xi,u)`, so `h` is analytic near zero. This proves a local unstable manifold

    W^u_loc={xi+h(xi)}.                                   (3.10)

Every stable Fourier mode in the infinite lattice is retained in (3.6)--(3.10).

## 4. Exact quadratic coefficient of the designated daughter

Order the four unstable positive-frequency parents as

    s_1=1/2,
    s_2=-2/5,
    s_3=1/5,
    s_4=-1/10,                                            (4.1)

with positive eigenvalues `lambda_j=gamma_+(1,s_j)`. The two designated pairs have common target

    k_*=p_1+p_2=p_3+p_4=(1/10,0,2),                       (4.2)

with stable eigenvalues

    lambda_*+ = gamma_+(2,1/20)<0,
    lambda_*- = gamma_-(2,1/20)<0.                        (4.3)

Write the full unordered Leray pair coefficients as

    F_A=beta_A+ a_+(1/20)+beta_A- a_-(1/20),
    F_B=beta_B+ a_+(1/20)+beta_B- a_-(1/20).              (4.4)

The quadratic term of the stable graph (3.9) divides each forcing channel by its causal growth mismatch. Put

    D_A+ =lambda_1+lambda_2-lambda_*+,
    D_B+ =lambda_3+lambda_4-lambda_*+,

    D_A- =lambda_1+lambda_2-lambda_*-,
    D_B- =lambda_3+lambda_4-lambda_*-.                    (4.5)

All four denominators are strictly positive.

Choose the two unstable pair products in the asymptotic coordinate `xi` with relative weights

    w_A= beta_B+ D_A+,
    w_B=-beta_A+ D_B+.                                    (4.6)

Then the target positive-branch coefficient in `h_2` is exactly

    w_A beta_A+/D_A+ + w_B beta_B+/D_B+ =0.               (4.7)

The target negative coefficient is

    H_- = w_A beta_A-/D_A-
          +w_B beta_B-/D_B-.                              (4.8)

The exact checker evaluates the algebraic quantities in (4.8) and proves

    H_->0.                                                 (4.9)

Hence the first nonzero target component on the **causal unstable manifold** is a pure negative source eigenbranch (up to the common Fourier phase). This is stronger and more relevant than canceling the instantaneous positive forcing, because (4.6) includes the complete linear prehistory denominators.

The products (4.6) are compatible with arbitrarily small real data. For a small scalar `epsilon`, choose the four complex unstable amplitudes so the first pair product is `epsilon^2 w_A` and the second is `epsilon^2 w_B`; a relative phase of `pi` realizes the negative sign. Reality fixes the negative-frequency amplitudes. Then

    P_(k_*,-) h(xi)
       = const * epsilon^2 H_- + O(epsilon^3),             (4.10)

while

    P_(k_*,+) h(xi)=O(epsilon^3).                          (4.11)

## 5. Meaning for the prehistory problem

This closes, in the full frozen reference lattice, the specific startup problem that defeated local pulse stitching. The decaying branch does not have to be independently prescribed at an entry face. It is generated by a single smooth nonlinear history extending to the remote past, and every stable sideband is part of the same solution.

Taking any finite `T>0`, the state `u(-T)` is one ordinary smooth datum of size `O(e^{-alpha T} epsilon)`. Evolving it by the same reference equation produces the target component without temporal delta impulses. Thus the model has an explicit mechanism by which an exponentially small remote seed can generate the otherwise hard decaying branch.

The next discriminator is **finite-`L` physical persistence**. The actual source principal operator is nonautonomous: labels and phase normals move, coefficients have `O(1/L)` corrections only on appropriate local windows, the source mean/pressure is coupled, and whole-space localization introduces radial exterior dynamics. The frozen manifold theorem is useful only if its hyperbolic cage and causal graph persist long enough under those physical changes to match one of the source pulse entry traces.

A successful next theorem must therefore construct a nonautonomous exponential dichotomy/graph transform for the actual finite-`L` principal history (with the complete stable complement), or find a precise loss showing that the `1/100` reference stable margin is overwhelmed before the required entry amplitude is produced.
