# Extreme-difference wall for finite all-growing source networks

Date: 2026-09-11. Repository input:
`itpplasma/navier@675709b351dc982ca813d99b76b143d8f7750765`.

**Status: exact leading-symbol obstruction for the natural finite source-eigenbranch family.** The September 10 regeneration packet showed that two growing source polarizations can seed a growing daughter, but necessarily create a competing difference-frequency shear. This note tests the simplest proposed repair: add finitely many more growing source-type parents at the same carrier magnitude and choose phases/amplitudes to cancel all difference outputs.

That repair is impossible. Every nonempty finite same-`b` family of distinct growing branches has an **extreme difference frequency** generated by exactly one unordered pair. Its full Leray coefficient is nonzero, so no phases or other parents can cancel it. Adding another growing parent only moves the obstruction to the new extreme pair.

This is a scoped obstruction. It does not exclude varying carrier magnitudes, mixed growing/decaying branches, an infinite family, spatial/time separation, or accepting the sideband as part of a new leading coupled system.

## 1. Source growing family

In the source reference frame `(e_r,N,K_tan)`, fix `b>0` and `c_0!=0`. For tilt `s` let

    p(s)=b(s,0,1),
    a_+(s)=(1,c_0 sqrt(1+s^2),-s).                       (1.1)

Then `p(s).a_+(s)=0`, and `a_+(s)` is the growing reference eigenpolarization already frozen in `2026-09-10-source-prehistory-regeneration.md`.

Take a finite family

    s_1 < s_2 < ... < s_N,

with nonzero complex amplitudes `A_j`. Reality adds the conjugate modes at `-p(s_j)`.

## 2. Difference coefficient for one pair

For `s_i != s_j`, write

    Delta=s_j-s_i,
    c=(s_j+s_i)/2,
    q_j=sqrt(1+s_j^2), q_i=sqrt(1+s_i^2).

The complete incompressible quadratic coefficient at the difference frequency `p(s_j)-p(s_i)` is, up to the common Fourier phase,

    C_diff
      = b Delta (0, c_0(q_j+q_i), -2c).                  (2.1)

This is the exact coefficient proved in the regeneration packet, with the Leray projection retained. Its squared Euclidean norm is

    |C_diff|^2
      = b^2 Delta^2 [ c_0^2(q_j+q_i)^2 + 4 c^2 ] >0.     (2.2)

Thus every distinct pair of growing branches has a nonzero difference output. A scalar phase changes only the complex prefactor `A_j conjugate(A_i)` and cannot make a nonzero coefficient vanish while both amplitudes are nonzero.

## 3. Extreme frequency is uniquely represented

For the ordered tilts above, the largest positive radial difference is

    p(s_N)-p(s_1)=b(s_N-s_1,0,0).                         (3.1)

If another pair `j>i` produced this same wavevector, then

    s_j-s_i=s_N-s_1.                                      (3.2)

But `s_j<=s_N` and `s_i>=s_1`. Equality of the differences forces both inequalities to be equalities, hence

    j=N, i=1.                                             (3.3)

So the extreme difference frequency has exactly one contributing pair in the entire finite parent set. Its coefficient in the real field is proportional to

    A_N conjugate(A_1) C_diff(s_N,s_1),                   (3.4)

and is nonzero by (2.2) whenever the endpoint amplitudes are nonzero.

No other growing-parent pair, and therefore no phase choice among the remaining parents, can cancel (3.4).

If one sets an endpoint amplitude to zero, remove that parent and repeat the argument on the smaller nonempty family. Hence:

**Theorem.** No finite nonempty same-`b` family of distinct source growing eigenbranches with nonzero active amplitudes can have every difference-frequency quadratic output vanish.

## 4. Consequence for source regeneration

The two-parent shear sideband found on September 10 is not an accident of using too few growing parents. Within this natural one-dimensional same-carrier source family, finite all-growing cancellation is structurally impossible.

The exact mixed-polarization escape from the predecessor remains important: for a symmetric pair `s,-s`, choosing opposite tangential polarizations can cancel the difference output while retaining a sum output. For the actual source eigenvectors that pairs one growing branch with one **decaying** branch. Therefore the next genuinely distinct question is not another finite growing-parent search; it is whether the decaying branch can be supplied dynamically or from the common physical prehistory at acceptable cost, or whether one must promote the shear sideband into a new leading coupled system.

The companion `research/check_source_extreme_difference.py` freezes (2.2). The uniqueness argument in Section 3 is analytic and does not require computation.
